# Rust 接口

`pier-rs` 包的 crate 名是 `levilamina`。每个模块一页；`Player`、`Entity`、`World` 这类类型的方法分在好几个源文件里，都合到它定义所在的那一页。

`levilamina::sys` 是 `abi.h` 的逐格镜像（`pier-sys-rs` 包），其中的槽位、常量和结构体见 [C++ 接口](../cpp/index.md)。
