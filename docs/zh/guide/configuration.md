# 配置 Pier

`plugins/Pier/config.json`。**只在不存在时写一次，之后再也不回写**，所以改过的东西都还在，
缺的键用默认值。

```json
{
  "language": "auto",
  "mods": {
    "disabled": []
  },
  "hooks": {
    "disabled": [],
    "decision_ttl_ms": 250
  }
}
```

宿主不读的键直接丢掉，一个字都不说。这里没有兼容层：不记旧的拼法，也不记已经没有的项。

## `language`

宿主说 `lang/<语言码>.lang` 里的哪一份。这个目录随发行包一起发，和 dll 放在一起；
宿主**只读不写**。

- `"auto"` 跟引擎报出来的语言走，只有一种语言的服务器就该用这个。
- 写别的值就是直接指定文件。`zh_CN` 和 `zh-CN` 都认；文件本身叫 `zh_CN.lang`，
  跟的是 Minecraft 自己的命名。

回退链是：选中的语言 → `en_US` → 键本身。翻到一半的文件按键回退，所以它在还没翻完的时候
就能用。

启动那一行会说这次是哪一边决定的——改了设置却没看到变化的服主，需要区分「这个值没生效」和
「那份翻译本来就没翻」：

```
[host] 语言 zh_CN（config.json 里指定的）：29 个键，来自 plugins/Pier/lang
```

指定了一个没有文件的码时，还会多出一行 WARN。因为上面那个键数看起来是健康的——内置英文
答得上每一个键——而服主要的东西一样都没生效。

加一门语言不需要重编：把 `en_US.lang` 复制成新的码，翻掉，丢进 `lang/`。
见[加一门语言](./adding-a-language)。

## `mods.disabled`

这个宿主拒绝装载的 Pier mod，按 manifest 名写。

```json
"mods": { "disabled": ["some-mod"] }
```

拒绝发生在**映射 dll 之前**，所以那个 mod 一行代码都不会跑：静态构造不会跑，`DllMain`
也不会跑。放到后面再拒绝，进来路上跑过的那些照样跑了，而那通常正是服主想拦的那一半。

名字必须和 manifest 完全一致。在这里做模糊匹配意味着会静默拒绝一个没人点名的 mod。

## `hooks.disabled`

不允许任何 mod 订阅的合成事件，按事件名写。

```json
"hooks": { "disabled": ["PlayerDropItemEvent"] }
```

订阅会被**拒绝**，不是静默丢掉，而且拒绝这一行带着是哪个 mod 在问。发给它一个永远不触发的
句柄，它会在接下来整局里都报告自己「正在保护」某样东西——而这正是这个宿主在别处到处在防的
那种失败。

用它来关掉某一条拦截而不卸掉想要这条拦截的 mod。那个 mod 接下来的行为会像这个事件根本不
存在一样，这一点要有预期。

## `hooks.decision_ttl_ms`

压力板和推挤的判定在缓存里留多久，毫秒。默认 250，也就是 5 刻。范围 0 到 5000，越界会钳住
并报出来。

这个缓存是刚需，不是优化。`entityInside` 对每一个站在板上的实体每刻跑一次，而每次派发都要
拼 SNBT、跨 FFI、在那边解析、查一次领地库、再跨回来。20Hz 下一个站着不动的玩家踩着压力板，
开销比其它所有东西加起来还大。

- **0** 是每刻都真派发。提供它是为了让正在测试的领地 mod 看到每一次调用，不是给正在跑的
  服务器用的。
- **调大**会拉宽「一条过期的放行活得比它读的那条领地规则还久」的窗口。坐标是缓存键的一部分，
  所以挪一格立刻失效；风险是玩家站着不动而他的权限在这期间变了。

## 文件读不出来的时候

每一项都退回默认值，**只影响这一局**，而且那行 error 会把后果直接说出来：
`mods.disabled` 这一局是空的，里面点名的 mod 照常装载。

**不拒绝启动。** Pier 是装载器，为了一个少写的逗号不肯起来，等于把服务器上所有 mod 一起
拖下水。宽松的那个方向才是危险的，所以它要被说出来，而不是只记一笔。
